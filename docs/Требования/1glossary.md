# Глоссарий

| Термин | Определение |
| --- | --- |
| **Пользователь** | Участник системы, имеющий учетную запись и одну из ролей: администратор, тренер или спортсмен. |
| **Администратор** | Пользователь с административными правами. Управляет тренерами и может управлять библиотекой упражнений. |
| **Тренер** | Пользователь, который ведет спортсменов, формирует группы, создает упражнения, назначает тренировки, контролирует выполнение и анализирует результаты. |
| **Спортсмен** | Пользователь, который получает тренировочные задания от тренера, выполняет упражнения и фиксирует результаты выполнения. |
| **Группа** | Объединение спортсменов, с которым работает тренер. Группа используется для организации спортсменов и назначения тренировок. |
| **Папка упражнений** | Раздел библиотеки упражнений, который помогает тренеру структурировать созданные упражнения. |
| **Упражнение** | Сущность, включающая название, описание и схему расположения шаров на столе. Упражнение создается тренером и затем может назначаться спортсменам в рамках тренировки. |
| **Позиция** | Схема расположения шаров на бильярдном столе. На уровне данных может включать шары, линии и дополнительные параметры, но на бизнес-уровне винт и сила удара рассматриваются как отдельные параметры упражнения. |
| **Биток** | Шар, по которому производится удар. |
| **Винт** | Точка попадания кием по битку, определяющая вращение шара. |
| **Сила удара** | Параметр упражнения, определяющий интенсивность выполнения удара. |
| **Тренировка** | Запланированное занятие группы спортсменов, в рамках которого тренер назначает каждому спортсмену набор упражнений. |
| **Задание тренировки** | Конкретное упражнение, назначенное конкретному спортсмену внутри тренировки. Содержит плановое количество попыток и результат выполнения. |
| **Результат выполнения** | Числовые данные, отражающие выполнение задания: количество попыток и количество успешных попыток. |
| **Статус тренировки** | Состояние тренировки в жизненном цикле: запланирована, выполняется, завершена, отменена, пропущена. |
| **Статус задания тренировки** | Состояние задания в жизненном цикле: не начато, выполняется, завершено, пропущено. |
| **Посещаемость** | Факт присутствия или отсутствия спортсмена на тренировке. |
| **Комментарий тренера** | Текстовое замечание тренера к тренировке или заданию спортсмена. |
| **Заметка спортсмена** | Текстовый комментарий спортсмена к выполнению тренировки или задания. |
| **Аналитика** | Представление данных о посещаемости, результативности и прогрессе спортсменов или групп за выбранный период. |
| **Мягкое удаление** | Способ удаления записи, при котором она перестает отображаться в обычных сценариях работы, но физически сохраняется в системе. |
